# 1.2.0 candidate - real Windows machines for your agent

**Candidate only: not tagged or published.** The public stable release remains v1.1.0.

This candidate combines the clean-machine app-testing loop with:

- Native interactive-desktop readiness and screenshots tied to a specific capture/window.
- Bounded desktop recording, self-contained HTML playback, optional host-encoded MP4 and interrupted-frame recovery.
- Concurrent CLI/MCP shared state, cooperative desktop turns and generation-safe cleanup.
- Encrypted/authenticated TCP and offline-mailbox transport with boot identity and replay rejection.
- Verified incremental warm deployment: no-change transfers, mutation/deletion, rollback and explicit process restart.
- Conservative host-only dependency diagnosis and explicit, verified Microsoft runtime provisioning.
- MSIX/Appx/bundle input handling and real AUMID activation; live matrix specifically proves native and WinUI MSIX.
- An agent-led setup guide with checksum verification, per-client registration, backup/preservation and admin/reboot consent.
- Fresh real-app imagery, a recorded UIA demo and a published workflow SHA256/build-provenance trail.

The integrated v1.1.0-version preview passed 95 unit tests plus real offline/TCP/firewall CLI/MCP, capture/recording,
native clean-versus-provisioned, WinUI EXE/MSIX and WPF tests. This 1.2.0 candidate must additionally pass the hosted
package checks and the exact downloaded artifact's real offline test before it is offered as ready.
See [measured compatibility](../compatibility.md); app/runtime/hardware coverage is not universal.

The default never installs app prerequisites. A provisioned pass is labeled non-clean. Windows Sandbox requires
supported Windows 11 editions, virtualization and one free guest slot. Actual UAC/lock transitions were not
induced in the recorded proof; native mock denial tests cover those guards.
